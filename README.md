# 🎮 Tic Tac Toe Game

A modern and responsive **Tic Tac Toe** game built using **HTML, CSS, and JavaScript**.

This project allows two players to play the classic X and O game with a clean interface, score tracking, winning animations, and a responsive design.

## ✨ Features

* 🎯 Two-player gameplay
* ❌ Player X and ⭕ Player O
* 🏆 Automatic winner detection
* 🤝 Draw detection
* 📊 Score tracking
* 🔄 Restart game option
* ✨ Winning combination highlight
* 🎨 Modern and professional UI
* 📱 Responsive design for mobile and desktop
* ⚡ Smooth hover and animation effects

## 🛠️ Technologies Used

* **HTML5** – Structure of the game
* **CSS3** – Styling, layout, colors, animations, and responsive design
* **JavaScript** – Game logic, player turns, winner detection, and score management

## 🎮 How to Play

1. Player X starts the game.
2. Players take turns selecting an empty box.
3. The first player to get **three symbols in a row** wins.
4. The three symbols can be:

   * Horizontally
   * Vertically
   * Diagonally
5. If all boxes are filled without a winner, the game ends in a draw.
6. Click **Restart Game** to start a new round.

## 🧠 Winning Patterns

The game checks these 8 possible winning combinations:

```text
[0, 1, 2]    [3, 4, 5]    [6, 7, 8]

[0, 3, 6]    [1, 4, 7]    [2, 5, 8]

[0, 4, 8]    [2, 4, 6]
```

## 🚀 How to Run the Project

### Method 1 — VS Code

1. Download or clone this repository.
2. Open the project folder in **VS Code**.
3. Open `index.html`.
4. Right-click on the file.
5. Select **Open with Live Server**.

The game will open in your browser.

### Method 2 — Directly in Browser

Simply double-click `index.html` and open it in your browser.
